## 学生申请

1. 每位成员注册或登录自己的 GitHub 账号。
2. 每组由一人提交[仓库权限申请](https://github.com/AI-wirelsee-classroom/2026-10-agent-course/issues/new?template=access-request.yml)，填写班级、两位课题编号、小组代号和全部成员的 GitHub 用户名。
3. 教师私下核对分组后，逐人发送已开通课题仓库的邀请；每位成员分别接受。待开通课题可先登记，建库后再邀请。
4. 按[学生提交指南](学生提交指南.md)克隆、修改 README 模板、推送分支并提交 PR。

申请公开可见，不要提交姓名、学号、电话、分组原表、密码或密钥。提交申请不等于自动获得权限；不要共享教师账号，也不要 Fork 成另一份作业仓库。

## 教师管理

按[教师权限管理与开课步骤](教师权限管理与开课步骤.md)审核、邀请和核验。只授权本组的私有仓库，不给学生课程管理仓库的写权限。

当前是个人账号：教师为仓库所有者，学生为对应项目的协作者；不使用组织或 Teams。GitHub Free 私有仓库的 PR 审核属于课程协作要求，不宣称平台已强制保护 main。[分支保护范围](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches)。

## 版本与交接

- 各小组自行填写、持续维护 README；目录按实际技术栈调整。
- 功能分支开发，通过 PR 合入 `main`；规格、实现、测试和评估同步维护。
- 不提交密钥、真实隐私数据、虚拟环境、构建产物、完整数据集或模型权重。
- 结课验收提交使用 `2026-10-final` 标签，验收后再归档本届仓库。
- 下一届新建年月班级仓库，例如 `2027-03-agent-07-research-literature`；同月不同班级增加班级后缀。继承成果时保留源仓库、提交历史及作者，不覆盖本届版本。
